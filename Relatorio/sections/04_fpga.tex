\subsection{Simulações no Vivado}

Na figura abaixo, encontra-se uma simulação realizada no ambiente Vivado, que demonstra o comportamento do sistema implementado na FPGA.

\vspace{1em}

Este teste consiste em aplicar o conjuntos de sinais de entrada que permite fazer o sistema evoluir do estado inicial até ao estado final, onde todas as peças foram processadas corretamente pelos tapetes transportadores e braços robóticos de acordo com a seguinte sequência:

\vspace{1em}
\begin{itemize}
    \item Caixa no Tapete 1 (\textit{saída - movi == '1'})
    \item Caixa no Braço 1 (\textit{saída - bot1 == '1'})
    \item Caixa no Tapete 2 (\textit{saída - movi\_2 == '1'})
    \item Caixa no Braço 2 (\textit{saída - bot2 == '1'})
    \item Caixa no Tapete 3 (\textit{saída - movi\_3 == '1'})
    \item Caixa no Braço 3 (\textit{saída - bot3 == '1'})
\end{itemize}\label{lst:sequence_signals}
