\section{Problema X - Distribuído com Buffers (Síncrono) e atraso entre eventos}

Neste problema foi nos pedido que fosse utilizado o sistema distribuído com buffers síncronos do problema IX e adicionando a este um atraso entre eventos, para isso foi utilizado um LFSR (Linear Feedback Shift Register) que gera números pseudoaleatórios que são usados para introduzir atrasos variáveis entre os eventos do sistema.

\vspace{1em}

Reunindo tanto os controladores em VHDL como o código relacionado com o LFSR, somente foi necessário construir um ficheiro main que interligasse estes compontentes para realizar esta parte do trabalho.
